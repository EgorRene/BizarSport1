BizarSport — установка как приложения (PWA)
1. Выложи папку на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages) или запусти локально:
   python3 -m http.server 8000   → открой http://localhost:8000
2. Chrome/Edge: значок «Установить» в адресной строке. Android: меню → «Установить приложение».
   iPhone: Safari → Поделиться → «На экран Домой».
Экономика: множители ECON (tvMul, sponsorMul, wageMul) в начале скрипта index.html.
ID приложения: поле "id" в manifest.webmanifest.
